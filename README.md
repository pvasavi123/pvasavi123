## 📌 Featured Projects

### 🏨 Hostel Management System
A mobile application designed to simplify hostel and property management operations for both owners and tenants.
*   **Technologies:** React Native, Expo, Django REST Framework, PostgreSQL
*   **Key Features:**
    *   Separate Owner and Tenant dashboard workflows.
    *   Dynamic property and room status management.
    *   Seamless tenant registration and tenant verification processes.
    *   Booking and approval request tracking.
    *   Real-time in-app notifications.

### 🛒 Retail Management System
A web-based application for managing complex retail operations, inventory tracking, and database synchronization.
*   **Technologies:** React.js, Spring Boot, MySQL, REST API
*   **Key Features:**
    *   Comprehensive product entry and category management.
    *   Secure transaction and stock level data management.
    *   Clean, modular REST API integration with Spring Boot.
    *   Structured relational database operations in MySQL.
    *   Fully responsive UI for inventory audits.

### 📋 Kanban Task Management Application
A visual task management dashboard designed to organize, prioritize, and track tasks through customizable workflow stages.
*   **Technologies:** React.js, Django REST Framework, Tailwind CSS
*   **Key Features:**
    *   Fluid drag-and-drop or state-button task organization.
    *   Interactive task creation, updating, and removal.
    *   Clean Django REST backend API integration.
    *   Sleek user interface built using modern CSS conventions.
